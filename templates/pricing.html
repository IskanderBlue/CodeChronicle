{% comment %} The five bands — name, price, control, inherit line, features — line up across every column because each card is a **subgrid**: the outer grid owns five rows, and every card spans all five and inherits those row tracks. So a band is as tall as the tallest card's version of it, and the features all start on the same line whatever sits above them. The inherit line ("Everything in Free, plus") is a band of its own rather than a heading inside the feature list. Free and Custom have no such line, and when it lived with the list their bullets started a line higher than everybody else's. An empty band still occupies its row. That is why there is no measured height anywhere here. The Team card's control is a button plus two labelled fields and every other card's is one button; a hand-set min-height would be a number read off a screenshot, wrong the moment a label wraps. {% endcomment %} {% comment %} The column count is a style, not a utility class: Tailwind compiles the class strings it can see in the source, so a name built from a variable would never exist in the stylesheet. The count moves when TEAMS_ENABLED is off (core.teams.teams_enabled), which drops the Team column. {% endcomment %}
