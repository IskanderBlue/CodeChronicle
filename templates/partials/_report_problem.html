{% comment %} "This looks wrong" — the reader's way to dispute a specific text. Sits in the attestation rail's trailing affordances, beside "How to read this", and wears the same ui-disclosure register as its neighbours. That placement is the argument: the rail is where the page makes its claim about how trustworthy this text is, so the invitation to dispute the claim belongs in the same line, not in a floating widget or a coloured badge. Expects a target, passed by whichever surface includes it: code_edition, division, provision_id, version — a provision report code_edition, reg_id — a regulation report report_surface — permalink / search / regulation The dialog teleports to body, like the commencement modal, because the rail and the clause cards clip a fixed overlay. Alpine state stays here in the including scope, so several reports on one search page never share a flag. The panel inside is a separate partial: HTMX fetches it when the dialog opens and swaps it in place on submit, so the ask, the thanks and the error are one file and cannot drift apart. Fetching rather than rendering it keeps the CSRF cookie off the page response, which is what lets the edge cache the page. {% endcomment %} {% comment %} `ui-state`: this span holds Alpine state and the teleport template, and must not be a box.
