How to call it

First search — this answers with the provisions that match, their editions and their dates: 

curl -X POST https://www.codechronicle.ca/api/search \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "guards and handrails", "date": "1999-06-01"}'

Then fetch the text of one, using the fields that result carries: 

curl -G https://www.codechronicle.ca/api/provision \
  -H "Authorization: Bearer YOUR_KEY" \
  -d edition=OBC_1997 -d division= -d id=9.8.7.1. \
  -d on=1999-06-01

Full endpoint reference: /api/docs.
