{% comment %} The on-screen controls of a printable page, and the only thing the print stylesheet hides that a reader would miss. Two of them. The print button waits for the images, because a crop with no measured image has no height yet and would print as a gap. The tables toggle decides whether a version's tables print again as their own figures: a scanned page already shows them, so the default for an image-rendered version is not to repeat them — see core.print_options for why that is a default and not a rule. The toggle is a link, not a checkbox: it re-renders the page, and a control that reloads should look like one. `tables_toggle_query` is built in the view so the comparison's two version references survive the flip. {% endcomment %}

No CSS can turn the stamp off — it is the reader's checkbox — so saying so is the only fix available from here. {% endcomment %}
