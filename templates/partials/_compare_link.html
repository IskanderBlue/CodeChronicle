{% comment %} Per-row "compare" affordance in the provenance rail. Opens ``/compare/`` on this row's version and the version being read. It used to hang ``?compare=`` off the permalink and render a second comparison in place. That was the same feature built twice: the in-place one could not cross an edition, had no redline floor — so two versions sharing almost nothing rendered as a wall of marked text with no explanation — and its URL named a permalink with a modifier rather than naming a comparison. There is now one comparison and one URL for it. Because nothing is toggled any more, there is no "comparing ×" state to keep in sync: the link navigates, and browser back is the way out. `target.compare_url` is built by ``core.compare.annotate_chain_comparisons`` — never here. The earlier version goes on the A side, and that ordering is a rule rather than a layout choice. Context: `target` — a CodeEditionProvisionVersion from the chain. {% endcomment %} {% if target.compare_url %} compare {% endif %}
